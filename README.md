# WGAAB Personal

Landing page estática do WGAAB Personal. A versão publicada fica na pasta `dist/`.

## Netlify

Conecte este repositório no Netlify. O arquivo `netlify.toml` já define `dist` como diretório de publicação; não é necessário comando de build.

## Atualizar o site

Edite `dist/index.html`, `dist/style.css` e `dist/app.js`. Imagens e fontes locais estão em `dist/assets/`.

A imagem da hero foi enviada pelo proprietário do site. As fontes Anton e Instrument Sans incluem seus arquivos de licença OFL junto aos arquivos de fonte.
